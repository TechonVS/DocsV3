This pages gives an overview of how to create an autonomous routine using PedroPathing. In this example, we write an autonomous for the 25-26 season DECODE. 
The robot starts in the blue far zone, in the corner of a tile. It scores its preloads and completes two cycles of picking up and scoring.
**Check the reference pages linked in this page to learn the basics for making your own auto-ops easily.**

## Step Two: Initializing poses
Poses are points on the fields that your robot will drive to. They contain 3 values, (`x`, `y`, `heading`). We use a [PoseFactory](/reference/posefactory) to create poses for our paths. 

Pedro’s coordinate system spans an interval of [0, 144] on both the x and y axes, with (0, 0) defined as the **bottom-left corner** of the field. To see more about the coordinate system, navigate to: [Coordinates](/docs/pathing/reference/coordinates). Below are the poses for our example autonomous:

```java title="ExampleAuto.java"
// continuing from the last bit of code 

//create our blank poses
private final Pose startPose, cycleOneAlign, cycleOnePickUp, cycleTwoAlign, cycleTwoPickup, leave;

public void buildPaths() {
        PoseFactory p = PoseFactory.degrees(); //use PoseFactory.radians() if you want to use radians
        startPose = p.of(56, 8, 90);
        cycleOneAlign = p.of(56, 36, 180);
        cycleOnePickUp = p.of(20, 36, 180);
        cycleTwoAlign = p.of(56, 60, 180);
        cycleTwoPickup = p.of(20, 60, 180);
        leave = p.of(34, 8, 90);
    }
```

## Step Three: Building the Autonomous Routine and Paths

We are using [**Ivy**](/docs/ivy), the official command library for Pedro Pathing,
to build your autonomous routine
To learn more about Ivy, check out the [Ivy documentation](/docs/ivy).

Here, our entire autonomous is in one big `sequential` command composition. So each command is ran one after another. 
We use Ivy's built in `follow` command to run each path. 
You can add your own commands between each path. Or use `parallel` compositions aswell.

We will create our [Paths](/docs/pathing/reference/api) within our autonomous routine, because we don't need to create them beforehand. We have used [Interpolation](/docs/pathing/reference/interpolation), which controls your robots heading, in our paths aswell (`.linear()` and `.constant()` for example)
<Callout title="For beginners" type="info">
 If your brand new to PedroPathing, or autonomous coding, you might be slightly confused, **we highly recommend reading the reference pages** linked to each word to learn what each word means. Lots of core parts of making PedroPathing autos are explained there
</Callout>

```java title="ExampleAuto.java"
public Command autoRoutine() {
    return sequential(
            // Here, we create a line for the robot to follow, .linear is our heading interpolation
            follow(follower, line(startPose, cycleOneAlign).linear(startPose, cycleOneAlign)),

            // This line doesnt have any interpolation added, it will instead turn to follow the line
            follow(follower, line(cycleOneAlign, cycleOnePickUp)),
 
            // This is a curve, first and last pose are your starting and ending points
            // The poses in between control the curve's shape
            follow(follower, curve(cycleOneAlign, cycleOnePickUp, startPose), true),
            
            // Cycle two, similar thing again
            follow(follower, line(startPose, cycleTwoAlign).linear(startPose, cycleTwoAlign)),
            follow(follower, line(cycleTwoAlign, cycleTwoPickUp)),
            follow(follower, curve(cycleTwoAlign, cycleTwoPickUp, startPose), true),

            // This line has constant heading interpolation, 
            follow(follower, line(startPose, leave).constant(startPose), true)
    );
}
```

## Step Four: Init and Loop Methods
The initialization phase sets up our paths and builds the auto command, while the loop runs the
scheduler and updates the follower. 

```java title="ExampleAuto.java"
@Override
public void runOpMode() {
    // These will run when the OpMode is initiated
    Scheduler.reset();
    follower = Constants.create(hardwareMap);
    buildPaths();
    // Set our starting position
    follower.setPose(startPose);
    follower.update();

    waitForStart();
    // We schedule all our commands when we start the OpMode
    schedule(autoRoutine());

    while (opModeIsActive()) {
        // Update the follower and execute the scheduler every loop
        follower.update();
        Scheduler.execute();

        // Feedback to Driver Hub for debugging
        telemetry.addData("x", follower.pose().x());
        telemetry.addData("y", follower.pose().y());
        telemetry.addData("heading", follower.pose().heading());
        if (follower.currentPath() != null) {
            telemetry.addData("Current path distance remaining", follower.distanceToEndpoint());
            telemetry.addData("Path number", follower.pathIndex());
        }
        telemetry.update();
    }
}}
```
